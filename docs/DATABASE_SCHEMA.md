# Database Schema

Database:

MySQL

---

# 1. Users

Stores login and account information.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| name | VARCHAR(100) | User name |
| email | VARCHAR(150) | Unique email |
| password | VARCHAR(255) | Hashed password |
| role | ENUM | PATIENT, CAREGIVER, DOCTOR, ADMIN |
| created_at | TIMESTAMP | Account creation time |

---

# 2. Patients

Stores patient information.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| user_id | INT | Related user |
| date_of_birth | DATE | Date of birth |
| gender | VARCHAR(20) | Gender |
| phone | VARCHAR(20) | Phone number |
| emergency_contact | VARCHAR(20) | Emergency contact |

Relationship:

patients.user_id → users.id

---

# 3. Medicines

Stores medicines prescribed/added for a patient.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| patient_id | INT | Patient |
| name | VARCHAR(100) | Medicine name |
| dosage | VARCHAR(50) | Dosage |
| instructions | VARCHAR(255) | Instructions |
| created_at | TIMESTAMP | Creation time |

Relationship:

medicines.patient_id → patients.id

---

# 4. Medication Schedules

Stores when medicines should be taken.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| medicine_id | INT | Medicine |
| time | TIME | Reminder time |
| frequency | VARCHAR(50) | Daily/Weekly/etc |
| start_date | DATE | Schedule start |
| end_date | DATE | Schedule end |
| is_active | BOOLEAN | Active status |

Relationship:

medication_schedules.medicine_id → medicines.id

---

# 5. Medication Logs

Stores whether the medicine was taken or missed.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| schedule_id | INT | Medication schedule |
| taken_at | DATETIME | Actual time |
| status | ENUM | TAKEN, MISSED, SKIPPED |

Relationship:

medication_logs.schedule_id → medication_schedules.id

---

# 6. Health Records

Stores patient health information.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| patient_id | INT | Patient |
| blood_pressure | VARCHAR(20) | Blood pressure |
| blood_sugar | DECIMAL(6,2) | Blood sugar |
| heart_rate | INT | Heart rate |
| temperature | DECIMAL(4,1) | Temperature |
| notes | TEXT | Additional information |
| recorded_at | DATETIME | Record time |

Relationship:

health_records.patient_id → patients.id

---

# 7. Alerts

Stores alerts generated by the system.

| Column | Type | Description |
|---|---|---|
| id | INT | Primary key |
| patient_id | INT | Patient |
| type | VARCHAR(50) | Alert type |
| message | TEXT | Alert message |
| severity | VARCHAR(20) | LOW/MEDIUM/HIGH |
| is_read | BOOLEAN | Read status |
| created_at | TIMESTAMP | Alert time |

Relationship:

alerts.patient_id → patients.id

---
